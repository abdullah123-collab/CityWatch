# CityWatch — Citizen Complaint Management System

## Project Overview

CityWatch is a simple, beginner-friendly frontend project built as a university DBMS assignment. It demonstrates how citizens can report civic issues and track complaint status. The frontend uses only HTML, CSS, and JavaScript (no frameworks).

## Features

- Report new complaints with category and description
- View complaint history with colored status badges
- Dashboard with quick statistics and recent complaints
- Simple client-side validation and dummy data storage (localStorage)

## Folder Structure

- index.html — Home page
- login.html — Login form
- dashboard.html — Dashboard with stats
- newComplaint.html — Form to submit complaints
- history.html — Complaint history table
- css/style.css — Main stylesheet
- js/script.js — JavaScript for UI and data handling
- images/ — Image assets (placeholder)
- database/citywatch.sql — Example SQL schema and sample data

## Technologies Used

- HTML5
- CSS3 (Flexbox, Grid)
- JavaScript (ES6)

## How to Run

1. Open the project folder in your browser (open `index.html`).
2. No server or backend is required — data is stored in `localStorage` for demo purposes.
